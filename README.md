# 工程简介

该项目来自黑马的redis学习项目黑马点评，本人只是在此基础上做了一个微服务的开发，学艺不精，经供参考，本人会在后续工作中将学到的知识一点点的加入到项目中来，不定期更新

技术栈：Springboot+Mybatis-Plus +Redis +MySQL +RocketMQ +Canal +Dubbo
2024.5-2024.8
- 项目描述：基于 Spring Cloud Alibaba 微服务架构开发的商户点评平台，采用 Dubbo 实现高性能 RPC 调用，整合 Redis、
RocketMQ、Canal 等中间件，实现高并发场景下的商户查询、优惠券秒杀、用户点赞等核心业务。
- 优惠券秒杀：通过 Redis+Lua 脚本实现库存预检和防重复购买，确保原子性。使用 RocketMQ 队列实现流量削峰以及解耦下单
和创建订单操作。消费端使用 Redisson 分布式锁保证同一用户订单串行处理，并保存订单到分片表。使用重试机制保证订单正
常创建，若失败后最多重试3次，重试间隔递增，异常订单发送告警并进行人工补偿。
- 限流：使用Jmeter计算秒杀接口塌陷区，使用RateLimiter的令牌桶算法进行限流，避免大量请求压垮服务，并保留一定的缓冲。
- 分库分表：基于ShardingSphere 实现订单表水平分片，使用用户ID作为分片键将订单表水平拆分为16个分片。通过合理的分
片策略，优化查询性能，解决了千万级订单数据的存储和查询瓶颈。
- 缓存主动更新：使用Redis存储商铺信息，支持用户快速查询。利用Canal监听MySQL binlog日志并发送MQ消息实现缓存数
据库一致性问题，提高数据一致性、避免缓存击穿、支持水平扩展，提升搜索效率和用户体验。
- 本地缓存优化：使用本地缓存保存 RPC 泛化调用代理实例，避免重复创建，提升性能；同时，通过 Guava 的 Interner 包装缓存
key，利用弱引用机制避免String引用不可回收的问题，防止内存泄漏。
